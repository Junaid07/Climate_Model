How to use this model

Follow the scientific routine: Predict → Change one control → Observe → Explain. This is a simple global-mean energy-balance model, not a GCM.

3. Guided student challenges

A — Double CO₂

Set CO₂ = 560 ppm, α = 0.30, λ = 1.2, C = 10.

Question: What is the final equilibrium warming? Does the temperature reach it immediately?

B — Ice loss

Return CO₂ to 280 ppm and lower albedo from 0.30 to 0.29.

Question: Why does lower albedo create positive forcing?

C — Ocean inertia

Use the same forcing and compare C = 5 with C = 30.

Question: Which warms faster? Does C change the final equilibrium?

D — Climate sensitivity

Keep forcing fixed and compare λ = 0.8 with λ = 1.8.

Question: Which model is more sensitive, and why?

Model limitation: This model represents global-mean energy balance only. It cannot simulate monsoon rainfall, wind circulation, regional climate, clouds explicitly, or individual weather events.
